# استمارات انتقال السباحين (PWA)

تطبيق ويب يعمل بالكامل داخل المتصفح: لا خادم ولا قاعدة بيانات.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا وارفع محتويات هذا المجلد إلى الفرع main.
2. Settings ← Pages ← Source: Deploy from a branch ← main / root.
3. افتح الرابط https://USERNAME.github.io/REPO/ على الجوال في Chrome.
4. من قائمة Chrome اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».

## الملفات
- index.html: التطبيق كاملًا (الواجهة، قراءة الإكسيل، رسم الاستمارة، كتابة PDF).
- template.png: قالب الاستمارة بدقة 200 نقطة في البوصة.
- xlsx.mini.min.js: مكتبة SheetJS 0.18.5 لقراءة ملفات الإكسيل.
- players-template.xlsx: قالب الإكسيل الفارغ.
- sw.js و manifest.webmanifest والأيقونات: للتثبيت والعمل بدون إنترنت.

عند تعديل أي ملف غيّر رقم الإصدار في أول سطر من sw.js (CACHE) ليصل التحديث للأجهزة.
